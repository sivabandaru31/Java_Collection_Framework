# Java Collections Framework – Java Practice

## 📌 About the Project

This repository contains my Java practice programs focused on the **Java Collections Framework** and problem-solving concepts.

It includes practical implementations of List, Set, Map, HashMap, HashSet, LinkedHashSet, TreeMap, TreeSet, Iterators, and commonly used collection operations.

The purpose of this repository is to strengthen my Core Java knowledge and improve my problem-solving skills for technical interviews.
